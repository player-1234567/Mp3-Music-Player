# Mp3 Music Player : 一款MP3本地音乐播放器

[ 项目框架 ] : 基于Flutter框架开发<br/>
[  UI框架  ] : 基于FluentUI design设计开发<br/>
[ 支持格式 ] : 仅Mp3格式<br/>
[  元数据  ] : 仅支持内嵌元数据[歌曲标题, 歌曲艺术家, 歌曲副标题, 歌曲专辑等], 内嵌封面和内嵌Lrc歌词<br/>
